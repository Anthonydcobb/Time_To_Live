# Notes for AI assistants

Read `HANDOFF.md` before doing anything. It says what's done, what's next, and the rules that come from the owner's design decisions.

- Run `npm test` and `npm run build` before you push. Both must pass.
- Keep `src/sim` free of DOM code, and add a test for every simulator change.
- Match real Cisco IOS output, but never use the Cisco name in game branding.
- Update `HANDOFF.md` when you finish something or a plan changes.
