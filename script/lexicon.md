# Time To Live: the lexicon

Words for the cosmic horror under Static Springs, and where they fit. This file is for writers
(Ant, Claude, agy, Hermes). The game never reads it; dialogue lives in `dialogue.md`.

## How to use them

- **One word per scene, inside a plain sentence.** The horror is the mundane voice slipping, not
  purple prose. Five of these in a line is parody; one in a line about a routing table is wrong
  in the right way.

  > WALTER: Routing table looks fine. Static route, default route, and one route to a network
  > that is ~non-Euclidean~. Probably a typo. Over.

- **Who says them:**
  - **Walter** fumbles them, like a word he read somewhere and isn't sure how to say.
  - **Mrs. Finch** never says them. Denial is her whole thing.
  - **Gus** says them flatly, as plain fact. He's been on shift since 1974.
  - **Gary** says them cheerfully, which is worse.
  - **Narration, the grimoire and the cult books** get the full purple version.
- **Network first.** The best uses pin a word to something technical: a topology, a lease, a
  cable, a log line. That keeps it Static Springs and not generic Lovecraft.

## Scale and indifference

| Word | Meaning | Where it fits |
|---|---|---|
| Aethereal | the thin upper air or deep space, where logic dissolves | Wireless (job 7): the signal goes somewhere *up* that isn't the sky |
| Abyssal | the deepest dark, where light can't reach | The bottom of a traceroute; a hop that answers from too far down |
| Antediluvian | from before the flood; older than history | Gus's 1974 log, a lease older than the router, a MAC from before networking |
| Immemorial | older than memory or record | The town's first network; `show version` uptime that's longer than the town has existed |
| Inchoate | just begun, formless | The thing in the wall at stage 1, before it's anything |
| Nebulous | hazy, cloud-like, shifting | What a broadcast storm looks like on the port lights |
| Primordial | from the very beginning, raw | The hotel's core switch (job 9); the first VLAN, VLAN 1, which you can never delete |
| Vastness | terrifyingly empty space | An unreachable network; a ping into nothing that never times out |

## The unfathomable

| Word | Meaning | Where it fits |
|---|---|---|
| Cyclopean | massive, built of huge irregular stones | The library or hotel server room: stone blocks instead of racks |
| Non-Euclidean | impossible geometry | Topology: a switching loop that shouldn't exist (STP, job 4), a traceroute with more hops than floors |
| Eldritch | weird, sinister, unearthly | Sparingly. It's the most worn-out word on the list |
| Stygian | dark, infernal (the River Styx) | The funeral home and crematorium (job 5) |
| Chthonic | of the underworld, deep below | Cable runs that go *down*; the crematorium basement, deeper than it should be |
| Tenebrous | dark, hard to see into | A port that's up/up but passes nothing; the back office with the lights out |
| Squamous | scaly, slimy | Cable insulation that's started to feel like scales. Use once, never explain |

## Dimension and distortion

| Word | Meaning | Where it fits |
|---|---|---|
| Angulated | sharp, jagged, unnatural angles that hurt to look at | A rack whose corners don't meet; the being's last stage, pressed against the glass |
| Byzantine | excessively complex and maze-like | A network diagram nobody can follow. Bonus: a *Byzantine fault* is a real networking term, for a node that lies to the others |
| Dimensional | of planes beyond our own | Where Fa0/24 actually goes. Walter calls it "the other side of the patch panel" |
| Fissure | a crack, in rock or in reality | The taped crack in the laundromat door; the seam in Gary's door where the tentacles come through |
| Prismatic | shifting colours, some that shouldn't exist | Fibre optics (later jobs): light in the cable in a colour you can't name |
| Transversal | crossing from one plane into another | A trunk link. It literally carries traffic between worlds (VLANs) |
| Vortex | a swirling portal pulling things into a void | A routing loop: packets circling until their TTL runs out. The game's name is *Time To Live* |

## Rites and occult lore

| Word | Meaning | Where it fits |
|---|---|---|
| Apostasy | abandoning a faith for another, uncaring god | A device that defects: a switch that stops listening to the root bridge (Root Guard's whole job) |
| Cabalistic | secret, esoteric doctrine | Hidden IOS commands; the `?` help that lists one command it shouldn't |
| Desecration | violating something sacred | `write erase` and `reload`: wiping a device's startup config. Walter treats it like grave robbing |
| Execration | a curse, or a look of loathing | IOS error lines (`%Error`, `% Invalid input`) written as curses in the grimoire's margins |
| Incantation | words spoken as a spell | **Already the game's word for commands**: learned like RPG skills, written into the grimoire |
| Litany | a repetitive chant that numbs the mind | Ping output. `!!!!!` is a litany; `.....` is the litany failing |
| Profane | unholy, contemptuous of the sacred | `enable password` stored in plain text, versus the consecrated `enable secret` |
| Thaumaturgy | working miracles, at an unnatural cost | Automation and scripts (job 9): it works, and something is paying for it |
